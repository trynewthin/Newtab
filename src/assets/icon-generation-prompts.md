# Icon Generation Prompts

This document documents the AI prompts used to generate the Modern UI style icons for the NewTab project. When creating new system icons, please follow this style guide to ensure consistency.

## Core Style Keywords
- **Modern UI / App Icon**
- **Flat minimalist design**
- **Soft, vibrant gradient background**
- **Clean white vector graphic (center)**
- **Squircle shape (Rounded Square)**
- **Apple iOS / Material Design style**
- **No realistic textures, no 3D depth effects (for the graphic)**

## Prompt Template
> Modern UI app icon for **[Item Name]**. Flat minimalist design with a soft, vibrant **[Color 1]-to-[Color 2]** gradient background. In the center, a simple, clean white vector graphic representing **[Object/Symbol]**. Squircle shape. Consistent style with Apple iOS or Material Design.
